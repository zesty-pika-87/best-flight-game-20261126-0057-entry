LANDASAN NUSANTARA: STOL Island Landings — fly the Cendrawasih STOL bush plane down a visible green glidepath corridor and land it on five named Indonesian island strips (Pantai Pasir, Kawah Merapi, Tebing Karang, Hutan Rawa, Malam Berlampu) across three mission types (mail run, timed medevac, night landing). Throttle discipline, centreline discipline, crosswind gusts, fuel and gear damage decide every sortie, and the live GLIDEPATH instrument plots your real descent trace against the ideal 3-degree line. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Play

Serve the game and open it in a desktop browser:

```
node serve.ts
```

Then open http://localhost:8080. Fly with W/S (throttle), arrow keys (pitch and bank), 1–5 to pick a strip, Space to fly, P to pause, R to fly again. No build step, no network requests, no sound files — all audio is synthesized with WebAudio.
